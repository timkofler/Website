Für Webseite, Speisekarte, WLAN oder Google-Bewertungen. Ohne Anmeldung, ohne Abo, ohne Werbung. Der Code läuft nie ab, und deine Eingaben verlassen deinen Browser nicht.

1Was soll der Code öffnen?

Webseite, Speisekarte, Online-Shop oder Instagram. Für Instagram genügt @name.

Wo finde ich diesen Link?
  1. Am Handy oder PC mit dem Google-Konto anmelden, mit dem du dein Unternehmensprofil verwaltest.
  2. Bei Google nach dem Namen deines Betriebs suchen (oder business.google.com öffnen). Dein Profil erscheint mit den Bearbeiten-Knöpfen.
  3. Auf „Rezensionen anfordern“ bzw. „Mehr Rezensionen erhalten“ tippen.
  4. Link kopieren und hier einfügen. Er sieht meist so aus: https://g.page/r/…/review

Noch kein Profil? So richtest du es ein: Google-Unternehmensprofil Schritt für Schritt.

Gäste verbinden sich mit einem Scan, ohne das Passwort abzutippen. Das Passwort steht im Code selbst: Wer den Code sieht, kann sich verbinden. Am besten nur fürs Gäste-WLAN verwenden.

[01] Ohne Haken

Ein QR-Code, der einfach bleibt.

Viele Generatoren locken mit „gratis“ und schalten den Code nach ein paar Wochen ab, bis man ein Abo abschließt. Hier gibt es das nicht.

  • Läuft nie ab

    Der Inhalt steckt direkt im Code, ohne Umweg über einen fremden Server. Es gibt nichts, das man abschalten könnte.

  • Bleibt bei dir

    Der Code entsteht in deinem Browser. Links, WLAN-Passwort und Logo werden nicht übertragen und nirgends gespeichert.

  • Kostenlos, ohne Anmeldung

    Kein Konto, kein Abo, keine Werbung, kein Wasserzeichen. Auch für den gewerblichen Einsatz.

  • Druckfertig

    PNG bis 2048 Pixel und SVG in Vektorqualität. Für Google-Bewertungen gibt es den Tisch-Aufsteller gleich dazu.

[02] Tipps für den Druck

Damit jeder Scan beim ersten Mal klappt.

Ein QR-Code ist robust, aber ein paar Dinge entscheiden, ob Gäste ihn sofort lesen können oder aufgeben.

  1. Groß genug

    Faustregel: Seitenlänge mindestens ein Zehntel des Scan-Abstands. Auf dem Tisch reichen 3 cm, am Plakat aus 2 m Entfernung eher 20 cm.

  2. Dunkel auf hell

    Dunkle Punkte auf hellem Grund lesen alle Handys. Helle Codes auf dunklem Grund oder blasse Farben machen manchen Kameras Probleme.

  3. Kurz und getestet

    Je kürzer der Link, desto gröber und leichter lesbar der Code. Vor dem Druck mit zwei Handys testen, auch aus etwas Abstand.

[03] Häufige Fragen

Gut zu wissen.

Läuft der QR-Code irgendwann ab?

Nein. Es ist ein statischer QR-Code: Der Link, die Telefonnummer oder die WLAN-Daten stehen direkt im Code. Es gibt keine Weiterleitung über meinen oder einen anderen Server, die abgeschaltet werden könnte. Solange dein Link funktioniert, funktioniert auch der Code.

Kostet das wirklich nichts?

Ja, der Generator ist kostenlos, ohne Anmeldung, ohne Abo und ohne Wasserzeichen. Du darfst die Codes auch gewerblich verwenden, etwa auf Speisekarte, Flyer, Rechnung oder Fahrzeug.

Werden meine Daten gespeichert?

Nein. Der Code wird mit JavaScript direkt in deinem Browser erzeugt. Links, WLAN-Passwörter und Logos werden nicht an mich oder Dritte übertragen. Die Seite setzt keine Cookies und hat kein Tracking.

Welches Format nehme ich zum Drucken?

Für die Druckerei am besten SVG: Das ist eine Vektordatei, die in jeder Größe scharf bleibt. Für Word, Canva oder den Drucker zu Hause reicht PNG mit 2048 Pixel. Für Bildschirm, Instagram oder E-Mail genügen 1024 Pixel.

Kann ich den Inhalt später ändern?

Den Inhalt eines gedruckten Codes nicht, das ist der Preis für „läuft nie ab“. Der Trick: Lass den Code auf eine Seite deiner eigenen Webseite zeigen, etwa dein-betrieb.at/speisekarte. Dort kannst du den Inhalt jederzeit ändern, der gedruckte Code bleibt gleich.
