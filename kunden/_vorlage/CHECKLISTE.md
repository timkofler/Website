# Checkliste

## Start
- [ ] Angebot angenommen
- [ ] Ordner `kunden/<benutzername>/` aus der Vorlage angelegt, Steckbrief ausgefüllt
- [ ] Eigener Thread im Claude-Projekt
- [ ] Zugang im Kundenportal angelegt (tim-kofler.at/kunden/admin/) und übergeben

## Inhalte (lädt der Kunde im Portal hoch)
- [ ] Logo (am besten SVG oder PNG mit transparentem Hintergrund)
- [ ] Fotos: Betrieb, Team, Produkte bzw. Leistungen
- [ ] Texte: über uns, Leistungen, Preise
- [ ] Kontakt, Öffnungszeiten, Adresse
- [ ] Angaben für das Impressum (Firmenbuch, UID, Kammer, Gewerbe)
- [ ] Bestätigt, dass die Bilder verwendet werden dürfen

## Umsetzung
- [ ] Inhalte in `inhalte.md` übernommen
- [ ] Entwurf in `seite/`, Vorschau-Link an den Kunden
- [ ] Korrekturen eingearbeitet
- [ ] Impressum und Datenschutz
- [ ] Domain, Webspace und SSL eingerichtet

## Livegang
- [ ] Seite veröffentlicht
- [ ] Freigabe vom Kunden
- [ ] Hochgeladene Dateien im Portal nach Abschluss gelöscht (spätestens 12 Monate)
