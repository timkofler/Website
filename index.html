Das Crypto-X Dashboard

Schluss mit Excel-Listen und zehn offenen Börsen-Tabs. Das Crypto-X Dashboard bündelt dein komplettes Krypto-Vermögen in einer klaren Oberfläche.

  • Alle Konten verbunden – Börsen per API (nur Leserechte) und Wallets per Adresse.
  • Live-Kurse & Performance – Gewinn/Verlust pro Coin, Zeitraum und Gesamtportfolio.
  • Steuer-Übersicht für Österreich – Alt- und Neuvermögen, KESt-relevante Erträge auf einen Blick.
  • Preisalarme – Benachrichtigung, wenn dein Zielkurs erreicht ist.
  • Datenschutz first – Server in der EU, keine Weitergabe deiner Daten.

FAQ

Häufige Fragen

Sind meine Coins im Dashboard sicher?

Das Dashboard verwendet ausschließlich API-Schlüssel mit Leserechten bzw. öffentliche Wallet-Adressen. Wir können keine Transaktionen ausführen und haben keinen Zugriff auf deine Coins.

Wo werden meine Daten gespeichert?

Auf Servern innerhalb der Europäischen Union. Details findest du in unserer Datenschutzerklärung.

Ersetzt die Steuer-Übersicht einen Steuerberater?

Nein. Die Übersicht hilft dir bei der Vorbereitung, ist aber keine Steuerberatung. Für deine Steuererklärung wende dich bitte an eine Steuerberaterin bzw. einen Steuerberater.

Kann ich jederzeit kündigen?

Ja, alle kostenpflichtigen Pläne sind monatlich kündbar.
